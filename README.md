# Quantum Router Communication System

## Overview

This repository contains the reconstructed quantum circuits,
Qiskit simulation code, numerical datasets, and analytical
validation data associated with the research paper:

**Design of a Quantum Communication System Integrating a
Quantum Router, Teleportation Circuit, and Quantum
Switching Mechanism**

## System Architecture

The proposed ten-qubit architecture integrates:

- Single-qubit RX(pi/2) rotation
- Controlled-SWAP (CSWAP) quantum routing
- Quantum Controlling Switch (QCS)
- Two unitary quantum state-transfer branches
- Hadamard, RZ, QFT, CCX, and RXX operations

The original architecture was designed in Quirk and
reconstructed in Qiskit for numerical evaluation.

## Input State Selection

A fixed dataset of 204 pure single-qubit states is used.

| State category | Count | Proportion |
|---|---:|---:|
| Deterministic states | 4 | 1.96% |
| Haar-random states | 200 | 98.04% |
| Total | 204 | 100% |

The deterministic states are |0>, |1>, |+>, and |+i>.

The random states are generated by normalizing complex
Gaussian vectors using NumPy's default_rng with seed 2026.

Explicit state preparation replaces the animated input
preparation gates of the original Quirk circuit.

## Simulation Results

### Ideal Statevector Simulation

| Metric | Mean fidelity |
|---|---:|
| Isolated state-transfer block | 1.0000 |
| Fixed-control routing | 1.0000 |
| Branch-conditioned transfer | 1.0000 |
| Unconditional lower receiver | 0.7468 |
| Unconditional upper receiver | 0.7468 |
| Analytical prediction for the dataset | 0.7468 |
| Theoretical Haar expectation | 0.7500 |

Each routing branch has a selection probability of 0.5
under balanced superposition control.

Control state |0> selects the lower receiver (q10),
while |1> selects the upper receiver (q3).

The maximum absolute difference between the simulated
unconditional fidelities and analytical predictions is
approximately 2.442e-15.

### Noisy Density-Matrix Simulation

Noise simulations evaluate the isolated three-qubit
state-transfer block.

| Simulation condition | Mean fidelity |
|---|---:|
| Ideal | 1.0000 |
| Low noise | 0.9690 |
| Higher noise | 0.8848 |

### Depolarizing Noise Parameters

| Logical gate arity | Low noise | Higher noise |
|---|---:|---:|
| Single-qubit | 0.005 | 0.020 |
| Two-qubit | 0.010 | 0.040 |
| Three-qubit | 0.020 | 0.080 |

Depolarizing channels are applied after logical gates
on their corresponding operands. The three-qubit QFT
is treated as a single logical operation.

These parameters are illustrative simulation assumptions,
not hardware-calibrated error rates. Input preparation
is ideal, and measurement errors are excluded.

```bash
python3 -m venv .venv
source .venv/bin/activate

```

## Reproducing the Results

Run the ideal simulation first:

```bash
python verify_quirk_qiskit.py
```

Then run the noisy simulation:

```bash
python verify_quirk_noise_qiskit.py
```

The scripts generate CSV datasets and noise metadata
in the repository directory.

The noise simulation checks that its input states
match the ideal simulation dataset.

## Research Scope and Limitations

This study evaluates circuit-level quantum routing,
state-dependent switching, and unitary state transfer
through numerical simulations.

The results do not constitute experimental validation
on physical quantum hardware or establish hardware-level
communication performance.

The noisy simulations use illustrative logical-gate
depolarizing channels rather than device-specific noise.
